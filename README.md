# Aarthi Gym Log

Personal workout logger built from a 4-day routine.

## Deploy on GitHub Pages

1. Create a new repo on github.com (e.g. `aarthi-gym-log`, public).
2. Upload the contents of this folder (just `index.html`) to the repo root.
3. Repo → **Settings → Pages → Source: Deploy from branch → `main` / `(root)` → Save**.
4. Wait ~30 seconds. Your app is live at `https://<username>.github.io/<repo>/`.

## Install on phone

Open the URL in Chrome on Android → ⋮ menu → **Add to Home screen**. Launches full-screen like a native app.

## Backup your data

Logs save to your browser's local storage. Tap **EXPORT** on the Progress tab periodically to download a JSON backup. Use **IMPORT** to restore on a new device.
